Value Contributed sums a player’s final team-value share in wins and losses. Wins Contributed sums that same value only when the player’s team won; Loss VC is the remainder from losses. VC / game is total Value Contributed divided by games played. Each game’s normalization is distributed across its weighted components before they roll up into Offense, Defense, Hustle, and Other, so those four segments add back to Value Contributed. A game with no attributable component routes its normalization-only value to Other.

Post rank Δ is regular-season Wins Contributed rank minus combined-postseason Wins Contributed rank. Positive means the player moved up in the postseason; negative means they fell. Both ranks use the same population: players who appeared in that season’s postseason. Postseason includes Play-In and playoff games, so a deep run can legitimately produce a large change.

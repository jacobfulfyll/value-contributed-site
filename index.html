How to read the table Wins VC is value in wins; VC/game uses all selected appearances.

Value Contributed sums a player’s final team-value share in wins and losses. Wins Contributed sums that same value only when the player’s team won; Loss VC is the remainder from losses. VC / game is total Value Contributed divided by games played. Each game’s normalization is distributed across its weighted components before they roll up into Offense, Defense and Hustle. Rank is the row’s place in the table as it is sorted right now, so choosing a different column renumbers it.

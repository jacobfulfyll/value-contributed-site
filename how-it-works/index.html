How Value Contributed works

The stat reads each game possession by possession, gives players credit or blame for recorded actions, adjusts that raw value for team and opponent context, then expresses each player’s positive share of the value created by that team in that game.

THE BIG PICTURE

One game becomes a set of player shares

Value Contributed does not say that a block is literally worth 0.8 wins. A number such as 0.80 is an action weight applied before the game is normalized. The final result answers: what share of this team’s game value belongs to each player?

  1. 1
    Read the possession

    Identify the shot, pass, rebound, turnover, defensive play, foul, and any linked contributors recorded in the data.

  2. 2
    Price each action

    Combine points or possession value with the action weights shown below. Credits are positive; mistakes are negative.

  3. 3
    Apply team and opponent context

    Reallocate offense and defense against opponent expectation, then apply actual game on/off and opponent-lineup strength.

  4. 4
    Build both time modes

    Recompute all_minutes and competitive from their own retained possessions.

  5. 5
    Build adjusted player totals

    Add adjusted offense and defense. Negative action value is retained through these stages so mistakes still matter.

  6. 6
    Close the positive team share

    Floor negative player-game totals at zero, then divide each positive total by the team’s positive total.

The public dashboard presents one statistic: Value Contributed. Value Contributed sums the result in every selected game; Wins Contributed sums it only in games the player’s team won.

HOW TO INTERPRET IT

A historical account of contribution, not a best-player rating

Value Contributed starts from the minutes and lineups coaches actually used, then attributes the value produced in those games to the players who were on the floor. It is deliberately retrospective: it describes what happened, in the context in which it happened.

Start with Wins VC. Sorting by Wins Contributed best matches the statistic’s purpose: showing how players contributed value in games their teams won. Total VC and VC per game are useful supporting views, but they answer different questions.

This is not a comparison with a league-average player, a forecast of future performance, or a claim about who is intrinsically “best.” Playing opportunity is part of the historical record, not something the model replaces with hypothetical equal minutes.

CONTEXT AND TEAM CLOSE

Raw offense and defense pass through three visible adjustments

The Player Values table exposes the same persisted stages used by the calculation. Offense and defense remain separate through the context pipeline so readers can see where value changed.

Raw value priced offensive actions + priced defensive actions (including defended shots)
Opponent expectation adjustment team offense/defense responsibility reallocation based on actual performance versus opponent expectation
Team game adjustment sign-aware actual target-game on/off multiplier
Opponent strength adjustment separate opponent defensive-lineup multiplier for offense and offensive-lineup multiplier for defense
Adjusted total adjusted offense + adjusted defense
Final game share max(adjusted total, 0) / team sum of positive totals

The adjustment columns show each stage’s signed change from the immediately preceding stage. Their percentages use gross raw offense or defense, not the signed net, so games with opposite signs do not create an unstable denominator. The stages multiply in sequence; the displayed changes are an audit trail, not independent what-if estimates. Each team-game’s final player shares sum to exactly 1.0.

MADE-SHOT CREDIT

How made scoring value is shared

The calculation uses recorded roles around the score—self-created or assisted, with any linked offensive rebound—not the basket’s shot subtype. The shares apply to the score’s face value.

Scoring situation Scorer Passer OREB Unassigned

OREB credit goes to the recorded rebounder or rebounders. The original shooter does not receive second-chance credit. Linked screens can use a separate role-sharing template.

SHOT DEFENSE

Defended shots use location; blocks use one fixed rate

A defended miss earns shot points × location rate. A defended make produces a penalty of −(shot points − opponent possession value) × rate. Exact blocks use 80% × blocked-shot face value.

Defended-shot location Rate
An exact block cannot also receive defended-shot credit. A block followed by a causal score is retained as a zero-value audit fact.

FROM ACTIONS TO FINAL VC

Actions become a positive share of one team-game

Raw action value signed outcome value × role coefficient × participant share
Adjusted offense and defense raw side + opponent expectation change + team-game change + opponent-strength change
Positive player total max(adjusted offense + adjusted defense, 0)
Final game share positive player total / team positive total

Made scoring starts with the two- or three-point face value and uses the role templates above. Misses and free throws compare realized points with team-specific expected value.

Negative actions remain part of the adjusted total, but a negative player-game total does not become a negative final team share. A DNP remains exactly zero.

CURRENT LIMITS

What this calculation still does not see

No gravity or deterrence estimate

It does not yet measure defenders avoiding a rim protector or defenders staying attached to an off-ball shooter.

No loose-ball or deflection bonus

Those counts are excluded because their overlap with steals, rebounds, and possession changes is not reliably resolved.

Team rebounds are not player rebounds

A team rebound remains audit information and is never spread across individual players.

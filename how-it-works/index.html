How Value Contributed works

The stat reads each game possession by possession, gives players credit or blame for recorded actions, adjusts that raw value for context and playing time, and turns it into each player’s share of one team-game of value.

THE BIG PICTURE

One game becomes a set of player shares

Value Contributed does not say that a block is literally worth 0.8 wins. A number such as 0.80 is an action weight applied before the game is normalized. The final result answers: what share of this team’s game value belongs to each player?

  1. 1
    Read the possession

    Identify the shot, pass, rebound, turnover, defensive play, foul, and any linked contributors recorded in the data.

  2. 2
    Price each action

    Combine points or possession value with the action weights shown below. Credits are positive; mistakes are negative.

  3. 3
    Apply player context

    Apply the player’s offense or defense factor, then account for how much of the team’s available time the player played.

  4. 4
    Normalize the team-game

    The active players’ results are converted into nonnegative shares that add to exactly 1.0 for that team in that game.

Value Contributed sums those shares in every selected game, including losses. Wins Contributed sums the same shares only in games the player’s team won.

MADE-SHOT CREDIT

The type of basket changes who gets credit

The current policy starts with the shot’s full face value—two or three points—then applies these shares to the recorded shooter and assister. A self-created jumper therefore gives substantially more credit to the shooter than an alley-oop does.

Shot type Shooter share Assister share

These are actor shares, not final VC. Rebounds, screens, secondary assists, and other linked actions can redistribute parts of the same possession’s value before team-game normalization.

SHOT DEFENSE

Defended shots and blocks use shot location

A defended miss earns shot points × location rate. A defended make produces a penalty of −(shot points − opponent possession value) × rate. An exact block uses the shot’s face value and a rate ten percentage points above the defended-shot rate.

FROM ACTIONS TO FINAL VC

The weights are only the first layer

Raw action value (points created − possessions used × PV) × action weight
Context-adjusted value raw action value × offense or defense factor
Playing-time value nonnegative adjusted score × player share of team time
Final game share player playing-time value ÷ team total

Made-shot shooter and assister rows are the important exception to the first shorthand formula: they start with the shot’s full two- or three-point face value, then use the shot-type shares shown above.

Before the playing-time step, if any active player has a negative adjusted score, the same offset is added to every active player so the lowest score becomes zero. DNPs remain zero. The team total is then normalized, so every team-game closes at 1.0 even when the team lost.

CURRENT LIMITS

What this calculation still does not see

No gravity or deterrence estimate

It does not yet measure defenders avoiding a rim protector or defenders staying attached to an off-ball shooter.

No loose-ball or deflection bonus

Those counts are excluded because their overlap with steals, rebounds, and possession changes is not reliably resolved.

Team rebounds are not player rebounds

A team rebound remains audit information and is never spread across individual players.

Calculated, not formally certified

The complete local calculation passed its current audits, but source freeze and independent certification remain separate.

How to read the table Wins VC is value in wins; VC/game uses all selected appearances.

Value Contributed sums a player’s final team-value share in wins and losses. Wins Contributed sums that same value only when the player’s team won; Loss VC is the remainder from losses. VC / game is total Value Contributed divided by games played; VC/G rank ranks that rate within the active season and schedule filters. Each game’s normalization is distributed across its weighted components before they roll up into Offense, Defense, Hustle, and Other, so those four segments add back to Value Contributed. A game with no attributable component routes its normalization-only value to Other.

Post VC/G Δ is combined-postseason VC per game minus regular-season VC per game. Positive means the player produced more value per appearance in the postseason. The comparison requires at least one game in each schedule and follows the selected season; All Seasons compares career rates. Postseason includes Play-In and playoff games. Post rank Δ is regular-season Wins Contributed rank minus combined-postseason Wins Contributed rank. Positive means the player moved up in the postseason; negative means they fell. Both ranks use the same population: players who appeared in that season’s postseason, so a deep run can legitimately produce a large change.

FULL-LINEUP CONTEXT

Six context magnifiers

A context magnifier of 1 preserves the measured effect, 0 removes it, and values above 1 amplify it.

ON / OFF

Reliability and importance

Small-sample shrinkage · K

K is the shrinkage applied to small off-court samples. K=0 applies the comparison fully; higher values pull small samples toward neutral.

On/off importance · λ

Lambda (λ) controls the importance of the player’s on/off performance. λ=0 ignores the off-court comparison; λ=1 uses it fully.

What do Original, after slider, and edited mean?

Original is the public policy value. After slider is the final value produced by the broad category, including any proportional rebalancing needed to keep the play at one possession. An Auto-balanced badge marks a connected role that was reduced. Edited replaces only this one role and is never changed automatically. Gray read-only values are recalculated from the final inputs.
